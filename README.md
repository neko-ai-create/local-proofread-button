# ローカル校正ボタン

Chromeへ読み込むフォルダは、この中の `extension` です。

`/Users/neko/校正ボタン/extension`

ボタンは入力欄の上側を優先して表示します。上側に置けないときだけ、他のボタンと重ならない空き場所へ移動します。

## ボタンの移動（0.2.2）

- 緑の「✓ 校正」を押したまま動かし、好きな位置で離します。
- 短くクリックすると校正します。移動だけでは校正しません。
- 移動先はそのページを開いている間だけ維持します。スクロールしても同じ画面位置に表示します。
- ページの再読み込み、またはボタンをTabキーで選んでEscキーを押すと自動配置に戻ります。
- 画面を小さくした場合も、画面外に出ないよう位置を調整します。

## 更新手順（削除は不要です）

1. Chromeのアドレス欄に `chrome://extensions` と入力します。
2. 右上の「デベロッパーモード」をオンにし、「ローカル校正ボタン」の丸い矢印（更新）を押します。
3. バージョンが **0.2.2** になったことを確認します。
4. 校正したいWebページも再読み込みして、入力欄をクリックします。

0.2.2にならない場合は別の保存先の版が登録されています。「パッケージ化されていない拡張機能を読み込む」で `/Users/neko/校正ボタン/extension` を選び、古い版はオフにしてください。

## 開発用テスト

Playwrightが利用できる環境で `node tests/drag.cjs` を実行します。必要なら `NODE_PATH` にPlaywrightのあるnode_modulesを指定します。MacのChromeを一時プロファイルで起動し、テストページのみを使用します。校正通信は固定応答に差し替え、実際の校正サーバーには送りません。別のChrome実行ファイルを使う場合は `CHROME_PATH`、画像保存には `SCREENSHOT_PATH` を指定できます。
